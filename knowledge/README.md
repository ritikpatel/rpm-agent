# Knowledge corpus

Project-authored **demo** protocols that the Summary and Escalation agents retrieve and cite. They restate widely known
principles in our own words (e.g. the published NEWS2 thresholds). They are **not clinical guidance**: before any
real use, a clinical governance team must replace them with approved local protocols. Licence: CC BY 4.0 (project
authors).

Each file starts with YAML-style front matter (`title`, `id`) followed by `##` sections; each section becomes one
retrievable chunk with a stable id (`<id>#<n>`) that briefs cite.
